# CHUCHU AI STUDIO — Client Files

## How to start a new client
Duplicate the `_CLIENT_TEMPLATE` folder and rename it to the client/company name.

Example:
`_CLIENT_TEMPLATE` → `CLIENT_COMPANY`

Then complete `CLIENT_RECORD.md` and keep all documents in their matching numbered folders.

## Standard structure
01_Proposal
02_Contract
03_SOW
04_Invoices
05_Client_Files
06_Final_Handover

## Important
Keep the blank master documents in `../templates/` untouched.

If this website folder is connected to a public GitHub repository, do not commit signed agreements, client addresses, invoices, private files, credentials, or other confidential client information.

## Standard workflow
Inquiry → Proposal → Agreement + SOW → Signatures → 30% deposit → Development → Beta/Acceptance → Final payment → Source-code handover → Optional maintenance.
