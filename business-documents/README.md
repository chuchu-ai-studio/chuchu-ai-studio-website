# CHUCHU AI STUDIO Business Documents

## templates
Blank master documents only. Never overwrite a master when preparing a client agreement.

## clients
Create one folder per client:
01_Proposal / 02_Contract / 03_SOW / 04_Invoices / 05_Client_Files / 06_Final_Handover

Do not commit signed contracts, client addresses, invoices, credentials, or confidential client files to a public website repository.

## Standard workflow
Inquiry -> Proposal -> Agreement + SOW -> Signatures -> 30% deposit -> Development -> Beta/Acceptance -> Final payment -> Source-code handover -> Optional maintenance.

## Start a client folder
For each new client, duplicate `clients/_CLIENT_TEMPLATE/` and rename the copy to the client/company name. Complete its `CLIENT_RECORD.md` and keep Proposal, Contract, SOW, Invoices, Client Files, and Final Handover in their matching numbered folders.
