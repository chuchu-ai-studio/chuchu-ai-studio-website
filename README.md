# CHUCHU AI STUDIO Website

Official website for **CHUCHU AI STUDIO — Mobile MVP & AI Product Development, Philippines**.

## Purpose

This site introduces CHUCHU AI STUDIO as a lean, professional product-development studio serving founders, startups, professionals, and companies internationally. It presents the studio's services, delivery process, selected product work, studio focus, and approach to product development.

## Website structure

- Hero and core capabilities
- Mobile MVP, prototype, production, AI, and web-to-mobile services
- Introductory USD project investment starting points
- Five-step product delivery process
- Selected product work
- Studio introduction and focus
- Product-development principles
- Project inquiry call to action

## Technologies used

- Semantic HTML5
- Modern CSS with responsive layouts and lightweight transitions
- Vanilla JavaScript for navigation, scroll behavior, and progressive reveal effects

No build tools, package manager, or application framework are required.

## Local preview

From the repository directory, start any static web server. For example:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in a browser.

## Deployment

The site is structured for deployment from the repository root with GitHub Pages. Deployment will be configured after review and approval.

Version 1 is in active review. The current workflow is: build → preview → approve → commit → push → deploy.
